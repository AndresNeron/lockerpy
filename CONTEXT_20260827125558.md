### File Summary
This project, `lockerpy`, is a comprehensive encryption toolkit designed to secure sensitive files using hybrid cryptography (RSA + AES). It provides functionality for encrypting/decrypting individual files or entire directories, with support for key generation, compression (gzip), and secure deletion of plaintext files. The system is built around a master RSA key pair (4096-bit) to encrypt a symmetric AES-256 key, which in turn encrypts the actual data, ensuring both security and performance. The project also includes experimental post-quantum cryptography (Kyber) and scripts for repository synchronization.

---

### Key Components

#### **1. Core Scripts**
- **`cipher.sh`**:
  - **Purpose**: Batch-encrypts all files in the `accounts/` directory using `locker -ae`.
  - **Key Logic**: Generates a sorted list of unencrypted files, then invokes `locker.py` to encrypt them with AES (using an RSA-decrypted symmetric key).
  - **Edge Case**: Skips already encrypted files (`.enc` extension).

- **`locker.py`**:
  - **CLI Interface**: Handles encryption/decryption workflows via command-line arguments (e.g., `-ae` for AES encryption, `-rd` for RSA decryption).
  - **Methods**:
    - `aes_treat_file(args, symmetric_key, path, enc_path, is_encryption)`: Orchestrates AES encryption/decryption, including gzip compression/decompression.
    - `parse_arguments()`: Defines CLI flags (e.g., `--path`, `--list`, `--save`).
    - `delete_file(path)`: Securely removes files post-encryption/decryption.
  - **Patterns**: Hybrid encryption (RSA for key exchange, AES for bulk data), file compression, and secure deletion.

- **`runtime_loader.py`**:
  - **Purpose**: Decrypts secrets (e.g., `.env.gz.enc`) at runtime without writing plaintext to disk.
  - **Methods**:
    - `runtime_decrypt_secret(enc_file_path)`: Decrypts a file using RSA (for the AES key) and AES (for the payload), then decompresses gzip content.
    - `load_secret()`: Loads decrypted key-value pairs into `os.environ`.

#### **2. Cryptographic Modules**
- **RSA (`/RSA/`)**:
  - **`encryption_rsa.py`**:
    - **`rsa_encrypt_path(public_key, file_path, enc_path)`**: Encrypts files with RSA-OAEP (SHA-256), enforcing size limits (4096-bit key = ~446 bytes max payload).
    - **`rsa_generate_keys(basename)`**: Generates 4096-bit RSA key pairs (PEM format).
  - **`decryption_rsa.py`**:
    - **`rsa_decrypt(private_key, encrypted_code)`**: Decrypts RSA-OAEP encrypted data.

- **AES (`/AES/`)**:
  - **`encryption_aes.py`**:
    - **`aes_encrypt_file(key, file_path)`**: Encrypts files with AES-256-CBC, including PKCS7 padding and IV generation.
  - **`decryption_aes.py`**:
    - **`aes_decrypt_file(key, encrypted_file)`**: Decrypts AES-CBC files, handling base64 encoding and padding removal.

- **Kyber (`/Kyber/`)**:
  - **`encryption_kyber.py`**: Experimental post-quantum encryption using the Kyber algorithm (shared-secret key exchange).

#### **3. Utilities**
- **`colors.py`**: Defines ANSI color codes for terminal output.
- **`push_repository.sh`**: Synchronizes code to a GitHub repository using `rsync` and `git`.

#### **4. Payloads (`/payloads/`)**
- **`encryption_aes.py`/`encryption_rsa.py`**: Standalone versions of the core encryption scripts for testing.
- **`lpayload1.py`**: Example script demonstrating AES encryption with a hardcoded RSA public key.

### Notable Patterns/Issues
- **Hybrid Encryption**: Combines RSA (asymmetric) for key exchange and AES (symmetric) for bulk encryption, balancing security and performance.
- **File Handling**: Uses gzip compression before encryption to reduce payload size. Securely deletes plaintext files post-encryption.
- **Key Management**: RSA private keys are stored in PEM format; AES keys are encrypted with RSA and stored separately.
- **Security Risks**:
  - **Key Exposure**: Private keys are stored unencrypted on disk (e.g., `.pem` files). Recommend password-protected PEM files or hardware security modules (HSMs).
  - **No Integrity Checks**: Missing HMAC or AEAD (e.g., AES-GCM) to verify ciphertext integrity.
  - **Hardcoded Keys**: `lpayload1.py` includes a hardcoded public key, which is a security anti-pattern.
- **Performance**: RSA encryption is limited to small payloads (≤446 bytes for 4096-bit keys). The project handles this by encrypting only the AES key with RSA.
- **Error Handling**: Basic error messages (e.g., file not found) but lacks detailed logging or recovery mechanisms.
